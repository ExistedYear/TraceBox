# TraceBox workflow

Source: the repository README and shipped product documentation.

1. Capture a report with reproduction steps, environment, expected behavior, and actual behavior.
2. Triage priority, severity, ownership, duplicates, and missing information.
3. Move work through a project-defined workflow with role checks and an immutable activity trail.
4. Connect pull requests and commits from approved GitHub repositories.
5. Check release readiness, blockers, and dependency impact before shipping.

Every write remains subject to project membership, issue visibility, workflow rules, and database authorization.
