# TraceBox workflow

Source: the repository README and shipped product documentation.

1. Capture a report with reproduction steps, environment, expected behavior, and actual behavior, supported by automated quality scoring.
2. Triage with advisory AI suggestions for priority, severity, ownership, and semantic duplicate detection.
3. Move work through a project-defined workflow with role checks, natural-language search, and an immutable activity trail.
4. Connect pull requests and commits from approved GitHub repositories.
5. Check release readiness, blockers, dependency blast radius, and AI release briefs before shipping.

Every write remains subject to project membership, issue visibility, workflow rules, and database authorization. Human approval is required for all triage and workflow changes.
